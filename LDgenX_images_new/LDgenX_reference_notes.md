# LDgenX — Reference notes and handoff

Created from LDgenX Photo Briefs.html. All 19 final images are original AI-generated illustrative scenes, exported as uncropped 1536 × 1024 landscape PNGs. Built-in image generation was used, followed by visual inspection and targeted edits. No project code was changed.

These scenes do not document LDgenX’s actual premises, staff, client sites, proprietary products or study results. Maps, charts and screen content are illustrative and must not be captioned as actual results. Equipment is generic. The references informed materials, species, working context and equipment geometry; they were not copied or used as final photographs.
